# RAG Insight — Homepage Responsive

## Cara membuka
Ekstrak seluruh ZIP ke satu folder, lalu buka index.html di browser. Tidak memerlukan instalasi, JavaScript, atau koneksi internet untuk tampilan dan navigasi internal. Link paper eksternal memerlukan internet.

## File
- index.html: homepage baru menggunakan semantic HTML.
- style.css: CSS eksternal khusus homepage.
- landing-page.css: CSS ringan untuk landing page, dipisahkan dari HTML tanpa mengubah aturan tampilannya.
- landing-page.html: halaman sebelumnya, dengan isi paper dan kelima anggota tetap dipertahankan. Ditambahkan tautan kembali ke homepage dan dihapus catatan pengisian anggota yang sudah tidak diperlukan.

## Enam ketentuan tugas
1. Hubungkan CSS: elemen link di head index.html memuat style.css.
2. Variabel dan reset: :root serta selector universal di awal style.css.
3. Header/hero: navigasi, judul, deskripsi, diagram alur RAG, dan tombol menuju ulasan.
4. Grid fitur: .feature-grid dengan empat card.
5. Media query: breakpoint 1000px dan 700px. Empat kolom menjadi dua lalu satu. Hero menjadi satu kolom pada mobile.
6. Uji desktop/mobile: rincian pemeriksaan ada di HASIL-UJI.md.

## Catatan pengumpulan
Paket berisi dua halaman: homepage baru dan satu landing page yang diberikan. Jika dosen mewajibkan dua landing page berbeda (tiga halaman total), tambahkan file landing page kedua dan tautan navigasinya sebelum dikumpulkan. Tidak dibuat tautan ke file yang belum tersedia.

Upload seluruh isi folder ini ke repository, pertahankan nama file dan posisi relatifnya. Homepage ini adalah situs informasi penelitian, bukan aplikasi AI yang menjalankan model RAG.
